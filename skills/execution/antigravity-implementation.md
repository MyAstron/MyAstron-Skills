# Antigravity Implementation

## Propósito

Transforma el plan recomendado por Gemini en una implementación real, ordenada, mantenible y documentada.

## Prioridad

Debe aplicarse como ejecución técnica prioritaria para proyectos personales de MyAstron.

## Principios

- respetar la arquitectura planificada
- mantener la lógica limpia
- evitar soluciones sobrecomplicadas
- documentar lo importante mientras se implementa
- mantener coherencia entre código y documentación

## Secuencia recomendada

1. estructura base
2. modelos o entidades
3. lógica principal
4. validación y manejo de errores
5. capa de entrada o interfaz
6. README y documentación
7. revisión final

## Qué debe producir

- estructura del proyecto
- código funcional
- README actualizado
- manual técnico básico
- manual de usuario si aplica
- diagramas o notas de flujo

## Prompt base

> Actúa como un desarrollador experto con enfoque en claridad y sostenibilidad. Implementa el proyecto respetando la arquitectura propuesta y la identidad de MyAstron. Mantén el código limpio, legible y ordenado, documenta decisiones relevantes y prioriza soluciones prácticas sobre complejidad innecesaria.
