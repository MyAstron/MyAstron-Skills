# install.md

## Instalación desde GitHub

Este repositorio puede instalarse como pack de skills desde la URL pública:

https://github.com/MyAstron/MyAstron-Skills

## Recomendación de uso

1. Copia la URL del repositorio
2. Pégala en tu agente o entorno que soporte carga de skills desde GitHub
3. Activa la skill que quieras usar
4. Si deseas priorizar tu identidad, usa la skill combinada

## Prioridad recomendada

- `myastron-priority-core` para uso diario
- `myastron-priority-core-deep` para proyectos complejos
- `myastron-identity-style` para documentación y diseño de docs
- `gemini-project-planner` para planificación
- `antigravity-implementation` para implementación técnica

## Nota

Si tu agente soporta carga por prioridad, configura primero la skill combinada para que siempre se aplique antes que otras generales.
